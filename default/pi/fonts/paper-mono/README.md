# Paper Mono desktop fonts

Unmodified official desktop TrueType files from [Paper Mono](https://paper.design/mono), pinned to [paper-design/paper-mono commit 74fc5537cc1f7b39aa8cccfa7dd3822e17143cca](https://github.com/paper-design/paper-mono/tree/74fc5537cc1f7b39aa8cccfa7dd3822e17143cca/fonts/ttf). Downloaded over HTTPS from that commit on November 6, 2026. The name table identifies Paper Mono; the OS/2 weight classes are 400 (Regular), 500 (Medium), 600 (SemiBold), and 700 (Bold). These are desktop fonts, not repurposed WOFF2 files.

The [SIL Open Font License 1.1](OFL.txt) is included unchanged. New Pi users receive private copies under `~/.local/share/fonts/paper-mono/` and a fontconfig preference only when no user fontconfig file exists. Keep the packaged Nerd Font and Omarchy icon font: Paper Mono does not replace their private-use glyphs. Existing users' fonts are not changed. Real fontconfig/Qt rendering and icon fallbacks still require Linux and Pi visual verification.
