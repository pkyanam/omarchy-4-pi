# README header artwork

Generated with the built-in imagegen tool on November 7, 2026. Final asset: `docs/assets/hero.png` (2172 × 724 PNG). The README uses a minimal horizontal composition: the Omarchy abstract mark, an X separator and the Raspberry Pi berry logo. There is no hardware device, wordmark or other text.

References inspected were the official [Omarchy mark](https://omarchy.org/brand/omarchy-logo.svg) and [favicon](https://omarchy.org/assets/images/favicon.png), and the official [Raspberry Pi symbol](https://www.raspberrypi.com/app/uploads/2022/02/COLOUR-Raspberry-Pi-Symbol-Registered.png). The final generated PNG was visually reviewed for the requested symbols, spacing and absence of words or a board. Marks remain the property of their respective owners; this is independent community-port artwork, not a sponsorship announcement.

## Generation brief

Compose the two reference marks at equal optical height on an opaque near-black background with generous margins. Keep Omarchy's stepped square geometry in lime, the Raspberry Pi berry in red with green leaves, and a smaller thin off-white X between them. Use crisp, flat edges and balanced spacing. Include only these three elements: no physical Pi, circuit board, photographs, words, captions, badges, frames or slogans.
