# Omarchy 4 Pi v0.2.0-alpha.4

This prerelease refreshes the Pi port from Omarchy 4.0.4 (upstream `quattro`, commit `d3cfd53b997f8bdcf776b8db68bf0d735e7a065d`) and retains the Raspberry Pi 4 installer, first-boot hostname provisioning, Pi-aware updates, performance defaults, and thermal protections.

The upstream refresh brings current desktop, Quickshell, agent-tooling, maintenance, and security fixes. Optional upstream applications still depend on ARM package availability. This image targets Raspberry Pi 4 Model B with 4GB or more RAM; stock clocks remain the default.

The previous candidate could not build because its third-party package snapshot host stopped resolving. This candidate uses signed packages from the official rolling Arch Linux ARM mirrors instead.

## Flash

Use Raspberry Pi Imager 2.0.11 or newer and choose the Omarchy 4 Pi entry from the release's `os-list.json`. Set the username, hostname, network, and SSH options in Imager. The image is built on GitHub's ARM runner; release assets include a compressed `.img.xz`, checksum, build manifest, audit report, and Imager catalog.

This is an alpha image, not a stable release. Back up important data and test it on a spare card. Report hardware results and issues at <https://github.com/pkyanam/omarchy-4-pi/issues>.
